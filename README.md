# Интерактивное бинго персонажа

Веб-приложение на React, TypeScript и Vite. Сборка сворачивается в один HTML-файл для GitHub Pages.

## Локальный запуск

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm ci
npm run build
```

GitHub Actions автоматически собирает проект и публикует папку `dist` в GitHub Pages при изменениях в ветке `main`.
